Kenapa live tidak di halaman ini

Console live adalah proses Python yang membaca data, menghitung sinyal, dan menulis audit log ke disk. GitHub Pages hanya menyajikan berkas statis, jadi tidak bisa menjalankannya.

Halaman HTTPS juga tidak boleh memanggil http://127.0.0.1:8787 dari browser (mixed content), dan backend sengaja hanya mengikat ke loopback. Jadi console live selalu dibuka langsung di mesin yang menjalankan bot.

Jalankan di komputermu

1

Siapkan lingkungan

cd aegis-one
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
2

Uji dulu tanpa jaringan

python tests.py                        # 48 unit test harus OK
python main.py --offline --interval 0.5 # data sintetis, uji guardrail
3

Jalankan dengan data pasar

python main.py                          # ccxt publik, tanpa API key
python main.py --csv data/BTCUSDT_15m.csv  # atau candle milikmu
4

Buka console

Alamatnya http://127.0.0.1:8787. Tombol di bawah hanya bekerja bila bot sedang jalan di perangkat ini.

Di VPS (24/7)

systemd

sudo cp deploy/aegis1.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now aegis1
sudo journalctl -u aegis1 -f

Akses console dari laptop

ssh -L 8787:127.0.0.1:8787 user@vps
# lalu buka http://127.0.0.1:8787

Jangan membuka port 8787 ke publik tanpa reverse proxy dan autentikasi.

Yang perlu diingat

  • Paket ini paper: AEGIS_LIVE_MODE=true akan ditolak sebelum menyentuh jaringan. Adapter eksekusi live tidak disertakan.
  • Kill-switch bisa diaktifkan dari console (dua langkah konfirmasi) atau dengan membuat berkas data/KILL_SWITCH.
  • Audit log tersimpan di data/aegis1.sqlite3 dan data/aegis1.jsonl — keduanya tidak masuk git.
  • Angka di console adalah hasil simulasi dengan fee, slippage, dan spread eksplisit. Bukan nasihat investasi dan bukan janji profit.
