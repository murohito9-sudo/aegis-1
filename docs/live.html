Local operations console

Untuk melihat runtime backend secara langsung, jalankan aplikasi lokal dalam lingkungan PAPER lalu buka halaman konsol operasional:

http://127.0.0.1:8787/live

Open local operations console ↗ Open PAPER / DEMO ↗

Console lokal membaca state melalui WebSocket backend dengan polling fallback. Panel menampilkan candle dan EMA, RSI, MACD, ATR, ROC, relative volume, rincian bobot/vote konfluensi strategi, alasan dan veto, quote bid/ask/spread, posisi, order, risiko, portfolio, briefing, riset, health, analitik, serta audit event. Nilai indikator dan diagnostik berasal dari Python engine dan hanya memakai candle tertutup. Kedalaman order book tetap ditandai belum tersedia bila feed tidak mengumpulkannya. Laporan dapat diekspor sebagai CSV atau Markdown.

Current verification boundary

VERIFIED IN REPOSITORY

Mode PAPER, feed market, indikator/strategi bersama, risk manager, audit log, reporting, monitoring, dan tampilan responsif diuji melalui fixture/offline CI.

NOT VERIFIED

Live account authorization, state reconciliation end-to-end, partial-fill aggregation dengan proteksi exchange, pemulihan proses, dan koneksi akun nyata.

  • Engine V3 tetap menolak startup saat LIVE diminta. Tidak ada bypass pada konsol browser.
  • Halaman operasional bersifat read-only dan tidak mempunyai tombol kirim order.
  • Jangan memasukkan API key atau secret ke halaman web, browser console, issue, atau log.
  • Pengujian yang tercatat di CI tidak membuktikan keamanan atau kesiapan produksi akun exchange.

Architecture target

Demo dan LIVE harus menggunakan market intelligence, indikator, strategi, risk engine, dan kontrak dashboard yang sama. Perbedaannya berada di adapter data/eksekusi serta ledger yang dipisahkan. LIVE hanya dapat dipertimbangkan setelah seluruh acceptance gate direview dan diuji menggunakan mock dan environment test yang terisolasi.
